# 📊 Northwind Data Analysis Project

## 🔍 Overview
This project is an end-to-end data analysis of the Northwind Traders dataset using SQL, Python, and Power BI to derive business insights.

---

## 🛠️ Tools Used
- SQL (MySQL Workbench)
- Python (Pandas, Jupyter Notebook)
- Power BI

---

## 📊 Dashboards

### 1. Sales Overview
- Revenue, Orders, AOV
- Monthly trends

### 2. Customer Insights
- Repeat vs one-time customers
- Customer segmentation

### 3. Product Analysis
- Category performance
- Product demand

### 4. Product Strategy & Performance Insights
- Pareto analysis (top revenue drivers)
- Revenue vs stability (scatter plot)
- KPI metrics (units/order, avg price, etc.)

---

## 🧠 Key Insights
- A small number of products generate most revenue (Pareto principle)
- Some high-revenue products show unstable demand
- Customer repeat behavior impacts revenue significantly

---

## 📁 Project Structure
- SQL queries for business analysis
- Python notebook for data cleaning & transformation
- Power BI dashboards for visualization
  
## 🚀 Conclusion
This project demonstrates a complete data analysis workflow from raw data to actionable business insights.
